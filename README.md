# PRIMAL Marketing Dashboard (app)

Vỏ app cài được (Edge / Chrome) cho dashboard việc team Marketing PRIMAL.
Bên trong là dashboard Apps Script thật; app chỉ thêm biểu tượng sư tử, cửa sổ riêng và số tin chat chưa đọc trên biểu tượng ở thanh tác vụ.

Cài: mở link GitHub Pages của repo này bằng Edge, bấm biểu tượng "Cài đặt ứng dụng" trên thanh địa chỉ, rồi ghim vào thanh tác vụ.

Mã nguồn dashboard nằm ở máy Khánh: `sales-marketing-dashboard\app\` (thư mục này là bản sao để đăng).
